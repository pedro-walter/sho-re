# Super Hang-On (Mega Drive / Genesis, World Rev A) – reverse engineering

Notes, tools and emulator scripts for understanding the Genesis *Super Hang-On*, with a focus on **Original mode**
(shop, mechanics, rivals, sponsors, part wear). **No game data is in this repo**: put your own ROM
(`Super Hang-On (World) (En,Ja) (Rev A).md`, 512 KB) in the repo root.

* `docs/01-overview.md` – dev environment (headless MAME + Lua), memory map basics, gotchas
* `docs/02-original-mode.md` – code structure of Original mode and the rules (wear, mechanics, payouts, phrases, part effects)
* `docs/03-original-mode-tables.md` – all tables read from the ROM (generated by `tools/tables.py`)
* `docs/04-track-data.md` – road curves per Original-mode track (generated by `tools/roadcurves.py`)
* `docs/05-track-storage.md` – how tracks are stored: sections, curve events, tile lists, rival -> track mapping (generated by `tools/trackdata.py`; `tools/patchrom.py` writes patched ROMs)
* `docs/06-arcade-timer-bug.md` – the Arcade lap-time carry bug, cause and tested fix
* `docs/00-questions.md` – the research agenda and its status

Quick start: `make disasm` (needs coverage files from `tools/cov.sh`, see docs/01), `tools/mame.sh scripts/play.lua`.
Everything runs headless; MAME never opens a window.
